Problem 1: Monthly Budget Analyzer

In the first program, I stored a student’s monthly expenses in separate variables such as rent, food, transport, and utilities. After that, I added all these values to calculate the total monthly expense.

Then, I set a budget limit of 60,000 PKR. Using an if-else condition, I checked whether the total expense was less than or equal to the budget limit. If it was within the limit, the student was considered within budget; otherwise, the student was over budget.

In this program, I used variables, arithmetic addition, and simple conditional logic.

Problem 2: Electricity Bill Estimator

In the second program, I took electricity units as input from the user and converted them into an integer. Then, I used an if-elif-else structure to determine which billing category the units fall into.

If the units were 100 or less, the basic rate was applied.

If the units were between 101 and 300, the standard rate was applied.

If the units were above 300, the high usage rate was applied.

In this program, I used user input handling, multiple conditions, and logical decision-making.

Problem 3: Class Attendance Analysis

In this program, I created a list of attendance percentages. Then, I initialized two counters: one for students who had attendance of 75% or higher, and another for those who did not meet the requirement.

I used a for loop to check each percentage in the list. If the percentage was 75 or above, the “meets requirement” counter was increased; otherwise, the other counter was increased.

At the end, I printed both totals. In this program, I used loops, counters, and conditional logic.

Problem 4: Scholarship Eligibility System

In this program, I used two lists: one for students’ CGPA and another for their family income. I then ran a loop that checked each student’s CGPA and income together.

I applied a compound condition to check whether the CGPA was 3.5 or higher and the family income was 80,000 PKR or less. If both conditions were true, the student was considered eligible for the scholarship, and the eligible counter was increased.

This program demonstrates how real-life scholarship rules can be implemented using logical conditions.

Problem 5: Sensor Alert System

In this program, I created a list of sensor readings and defined a safe range between 20 and 80. Then, I used a loop to check each reading. If any value fell outside the safe range, the alert counter was increased.

After checking all readings, I calculated the total number of readings and computed the percentage of unsafe readings.

In this program, I used accumulators, logical checking, and percentage calculation.
